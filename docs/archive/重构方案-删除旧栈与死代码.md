## 1. 目标

1. 移除生产路径不 import 的 Agno/Gradio 旧栈层（agent.py / llm.py / pipeline.py / ui.py）。
2. 移除不可达的 Phase 2 死分支（`_ENABLE_PHASE2=False` 下 ~110 行零调用者代码）。
3. 彻底移除 ASR 路径（faster-whisper），多模态成为唯一总结路径。
4. 移除全局单例 `_live`/`_live_summary` 及其连带（main.py SSE 回退分支、兼容函数）。
5. 移除零消费者死代码（shim、hotboard、backcompat 分发器、tool_definitions、前端死导出、死依赖）。
6. 修复 2 个因 shim 而失效的活代码测试（改 import，非行为变更）。

**行为等价性保证**：所有删除项在生产路径上均为不可达（`_ENABLE_PHASE2=False`）或零消费（见第 5 节论证）。删除后生产行为与删除前完全一致。
